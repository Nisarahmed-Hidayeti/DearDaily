# DearDaily

**Every day has a story.** DearDaily is a journal for writing privately and sharing selected stories when you choose.

## Open the website

[deardailyy.netlify.app](https://deardailyy.netlify.app)

## What you can do

- Write and organize journal entries, with automatic saving and voice notes.
- Format selected text with bold, underline, font choices, text color, and highlighting.
- Personalize pages with covers, icons, photos, and music.
- Keep entries private, or publish stories and manage a public profile.
- Browse published writing and use the site on desktop or mobile.

Cover artwork credits and rights information are listed in [the image sources](public/covers/SOURCES.json).

## Built with

React, TypeScript, Vite, and Supabase.
